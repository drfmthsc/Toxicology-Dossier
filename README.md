# Forensic Toxicology — Flashcards & Quiz

An interactive, self-contained study tool for **MBBS and postgraduate Forensic Medicine**,
covering the classical poison classification with flip-flashcards and a self-scoring MCQ drill.

**475 quiz questions** and **43 flashcards** across eight categories: General & medico-legal,
Corrosives, Irritants (metallic, plant & animal), Neurotics (CNS), Cardiac poisons,
Asphyxiants, Agrochemicals/pesticides, and History of Toxicology.

## Live site

Once GitHub Pages is enabled (see below), the tool runs at:
`https://<your-username>.github.io/<repo-name>/`

## Using it

- Open the page — no installation, no login, works offline once loaded.
- **Flashcards:** tap a card or press Space to flip; ← → to move; shuffle to randomise.
- **Quiz:** pick an answer for instant feedback and a running score.
- Filter either mode by poison class.
